# Task Management Application

A modern, responsive task management application built with Angular 20, featuring user authentication, task management, and a beautiful Bootstrap-based UI.

## Features

### User Authentication

- **Secure Login/Register**: Complete user authentication system
- **Form Validation**: Real-time validation with user-friendly error messages
- **Password Visibility Toggle**: Enhanced UX with show/hide password functionality
- **Route Guards**: Protected routes for authenticated users

### Task Management

- **Create Tasks**: Add new tasks with detailed information
- **View Tasks**: Organized task listing with modern UI
- **Task Forms**: Intuitive forms for task creation and editing
- **Responsive Design**: Works seamlessly on desktop and mobile devices

### Architecture

- **Angular 20**: Latest Angular features and performance improvements
- **Standalone Components**: Modern Angular architecture
- **Reactive Forms**: Type-safe form handling
- **Service Layer**: Clean separation of concerns
- **TypeScript**: Full type safety and better development experience

## Getting Started

### Prerequisites

- **Node.js** (v18 or higher)
- **npm** (v9 or higher)
- **Angular CLI** (v20 or higher)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/PraveenJayaratnam/Task-Management-App.git
   cd task-management-app
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:4200`
